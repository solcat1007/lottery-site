网站导航栏包含三个入口：

  • 大家的照片 — 公共墙，展示所有用户同意公开的照片

四、抽奖流程

用户首次访问网站时，系统会弹出身份登记框，要求填写 COS名称 和 微信号。确认参与后，系统在服务端从奖池中随机抽取一个结果，并通过抽奖动画展示中奖信息。中奖后页面自动跳转至"我的照片"页。

说明：每个 COS 名称 + 微信号组合只能参与一次抽奖，重复提交会被拒绝。管理员账号可无限次抽奖用于测试。

五、照片上传与展示

5.1 上传照片

用户在"我的照片"页可以上传自己的照片。点击白色框选择图片后，确认上传即可，系统会自动将照片放入空位（最多 9 张）。支持的图片格式包括 JPG、PNG、GIF、WebP 以及 iPhone 默认的 HEIC 格式，单张图片大小限制为 25MB。

5.2 同意公开

用户上传的照片默认仅自己可见。如需展示在"大家的照片"公共墙，需用户本人点击照片下方的"同意公开"按钮。管理员无权代替用户操作公开或撤回已公开的照片。

十、技术说明

网站后端采用 Python Flask 框架，配合 Gunicorn 部署在阿里云香港服务器（2核4G）上，由 Nginx 反向代理对外提供服务。数据以 JSON 文件形式存储，图片存储在服务器本地磁盘。抽奖采用 50 人固定奖池机制，中奖结果在服务端随机生成，杜绝前端作弊。
